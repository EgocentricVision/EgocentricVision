How it works

The first time you submit, you'll be asked for a classic GitHub Personal Access Token with just the public_repo scope. Any GitHub account can create one — you don't need to be a collaborator here. It's saved only in this browser's localStorage and used to call api.github.com directly.

Submitting forks this repository under your account (if you haven't already) and opens a Pull Request from there. Nothing is published automatically — a maintainer reviews and merges it, which then triggers the GitHub Action that regenerates the public page.
