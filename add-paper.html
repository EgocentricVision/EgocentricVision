How it works / security notes

At first use you'll be asked for a GitHub Personal Access Token, fine-grained, scoped to only this repository, with Contents: Read and write and Pull requests: Read and write permissions. It's stored only in this browser's localStorage and used to call api.github.com directly — it's never sent anywhere else.

Don't share this page's link while your token is saved, unless you want whoever opens it to be able to write to the repository.

Merging the Pull Request (a manual review step) triggers the GitHub Action that regenerates the public page.
