Incolla qui sotto una o più righe CSV già pronte (stesso schema di tools/egodata.csv, ad esempio esportate da Elynd). Al click su "Apri Pull Request" viene creato un branch, aggiunte le righe a tools/egodata.csv e aperta una Pull Request verso gh-pages per la revisione.

Come funziona / note

Al primo utilizzo viene richiesto un GitHub Personal Access Token fine-grained, con accesso limitato a questo solo repository e permessi Contents: Read and write + Pull requests: Read and write. Il token viene salvato solo nel localStorage di questo browser e usato per chiamare direttamente api.github.com: non viene mai inviato altrove.

Non condividere il link di questa pagina con la capacità di scrittura attiva (token già salvato) se non vuoi che chi la apre possa scrivere nel repository.

Il merge della Pull Request (passo manuale di revisione) fa scattare la GitHub Action che rigenera automaticamente la pagina pubblica.
